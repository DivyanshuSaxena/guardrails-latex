\section{Guardrails}\label{sec:guardrails}

\begin{itemize}
    \item Guardrail = (Property, Trigger, and Action)
    \item An OS policy developer can specify the guardrail that must accompany a learned policy.
    \item Our tool can then generate the code that implements the guardrail.
    \item At runtime, the guardrail is checked, and the action is taken if the trigger is activated.
\end{itemize}
