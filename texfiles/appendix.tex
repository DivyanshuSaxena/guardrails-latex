% A system state is a mapping from variables to values
% $\s : \Var \to \Val$. We write the set of states $\States$ A system $\Sys$ is a tuple $\langle \s_0, {\SStep{}{}{}} \rangle$ of an initial state $\s_0$ and a deterministic step relation $\SStep{\s}{\event}{\s'}$ that updates the state from $\s$ to $\s'$ corresponding to an event $\event \in \Events$ from some fixed set of events $\Events$. As shorthand we will write $\SysNext{\Sys}{\s}{\event}$ for the set of states $\s'$ s.t. $\SStep{\s}{\event}{\s'}$. We also define $\SStepN{\s}{\event_1\cdots\event_n}{\s'}$ as the lifting of ${\SStep{}{}{}}$ to sequences of events.

% A \emph{trace} is a (nonempty, infinite or finite) alternating sequence of states and events $\trace = \s_0\event_1\s_1\event_2\ldots \in \States \times (\Events \times \States)^*$. We write $\Traces$ for this set of traces. A trace $\trace = \s_0\event_1\s_1\event_2$ is valid for a system $S = \langle \s^*_0, \SStep{}{}{}\rangle$, if $\s_0 = \s^*_0$ and forall $i \geq 0$, $\SStep{\s_i}{\event_{i+1}}{\s_{i+1}}$. To extend a trace $\trace$ with an event-state pair $(\event, \s)$, write $\TExtend{\trace}{\event}{\s}$. To restrict a trace to only the most recent $k$ states, write $\TRestrict{k}{\trace}$.
